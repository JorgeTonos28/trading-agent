# R-006 — Probe wave 01: Plus/Codex y activos públicos Anthropic

**Fecha:** 2026-10-01. **Estado:** evidencia parcial; no selección ni implementación. **Alcance:** [ADR-007](../decisions/ADR-007-r006-openai-anthropic-plus-scope.md). No se invocó OpenAI API con clave, Anthropic API, Claude Managed Agents, broker ni conector financiero de pago. Descargas de código público solo a directorio temporal fuera del repositorio.

**Aclaración 2026-10-02:** todas las observaciones de CLI, Skills y catálogo en esta wave son de `CURRENT_RESEARCH_ENVIRONMENT` (`planType=team`). `TARGET_RUNTIME_ENVIRONMENT` es ChatGPT Plus **individual**. Por tanto, las capacidades dependientes del plan tienen `AVAILABLE_IN_RESEARCH_ENVIRONMENT` según el probe y `AVAILABLE_IN_TARGET_PLUS=UNKNOWN` salvo evidencia específica; este informe no valida la cuenta Plus objetivo.

## 1. Rutas de coste: distinción necesaria

La [página oficial de precios de Codex](https://learn.chatgpt.com/docs/pricing) incluye Codex en Plus y advierte que los precios de tokens API son separados del uso de suscripción. Una aplicación que use **API key y facturación de plataforma** sigue siendo Tier 2 por defecto bajo ADR-007. La existencia de código público de Agents SDK no transforma esa ruta en entitlement Plus.

Existe además una ruta distinta documentada por OpenAI: [Sign in with ChatGPT, uso del plan para aplicaciones open source/locales](https://developers.openai.com/siwc/token-sharing-open-source). Su OAuth puede autorizar solicitudes elegibles de Responses usando el cupo del plan, sin API key de proyecto. La [guía de Codex app-server](https://developers.openai.com/siwc/token-sharing-open-source/codex-app-server) describe un host local que usa ese token y herramientas locales. Esto **no** demuestra todavía elegibilidad de nuestra cuenta, aptitud para servicio desatendido, disponibilidad de modelo, presupuesto suficiente ni compatibilidad completa del Trading OS. `C-025` es candidato Tier 0/1 **condicional**, `PENDING`; la API con clave C-012/013 sigue Tier 2.

Los [límites de preview](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations) exigen `store:false` y `stream:true`, restringen estado y campos, y excluyen herramientas alojadas como MCP/connectors, file search y code interpreter por esa ruta. Codex app-server puede exponer shell/MCP **local** mediante tools compatibles. Estos límites importan para auditoría, datos y recovery; no se infiere que el Agents SDK completo funcione sobre SIWC. El cupo Plus se comparte con otras aplicaciones según [Accounts and sessions](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions). La capacidad de operación continua PAPER V1 sigue abierta.
